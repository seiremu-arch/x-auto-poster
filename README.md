# x-auto-poster

## ぷにスケジュール

余裕があるうちは丸くぷにぷに、予定を詰め込むほど角丸四角 → 完全な四角へと硬くなっていくスケジュールアプリです。

- 1日に使える時間（分）を設定します。
- タイトルと所要時間を入力して予定を追加すると、その時点での「詰まり具合」に応じてブロックの形と色が決まります。
  - 空きが多いとき: 丸くて柔らかい（ぷにぷに）ブロック
  - 詰まってくるとき: 角丸四角のブロック
  - 満杯に近いとき: 完全な四角のカチコチなブロック
- 容量を超える予定は追加できず、ジャーが揺れて知らせます。
- ブロックはクリックすると削除できます。
- 状態はその日の分だけブラウザの `localStorage` に保存されます。

### 使い方

ビルド不要の静的アプリです。`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

ファイル構成:

- `index.html` — マークアップ
- `style.css` — スタイルとアニメーション
- `app.js` — 予定の追加・削除、丸 → 四角の形状計算ロジック
