# x-auto-poster

## ぷにスケジュール

余裕があるうちは丸くぷにぷに、予定を詰め込むほど角丸四角 → 完全な四角へと硬くなっていくスケジュールアプリです。

### 年間の構造

- 今日から1年間を「12週間＋お休み1週間」＝13週間のサイクルで区切り、4サイクル（52週）分の年間ビューを表示します。
- お休み週は予定を入れないバッファ週で、次のサイクルに向けたリセット地点です。
- 年間ビューの各週セルも、その週の埋まり具合に応じて丸 → 四角に変化します。週をクリックするとその週（7日間）の詳細に進めます。

### 週・日の使い方

- 上部で1日に使える時間（分）を設定します（全ての日に共通）。
- 週ビューでは曜日タブと7日分のミニプレビューが並び、選んだ日にタイトルと所要時間を入力して予定を追加できます。
- 予定を追加すると、その時点での「詰まり具合」に応じてブロックの形と色が決まります。
  - 空きが多いとき: 丸くて柔らかい（ぷにぷに）ブロック
  - 詰まってくるとき: 角丸四角のブロック
  - 満杯に近いとき: 完全な四角のカチコチなブロック
- 容量を超える予定は追加できず、ジャーが揺れて知らせます。
- ブロックはクリックすると削除できます。
- 状態はブラウザの `localStorage` に保存されます（年の開始日・1日の容量・各日の予定）。

### 使い方

ビルド不要の静的アプリです。`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

ファイル構成:

- `index.html` — マークアップ（年間ビュー・週ビューは `app.js` が描画）
- `style.css` — スタイルとアニメーション
- `app.js` — 年/週/日の状態管理、ルーティング、丸 → 四角の形状計算ロジック
