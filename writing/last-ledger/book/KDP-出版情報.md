```bash

python3 writing/last-ledger/build_epub.py    # 縦書きEPUB
python3 writing/last-ledger/build_epub.py --horizontal   # 横書きEPUB
```

## 2. ★著者名

EPUB内の著者名は `著者名未設定` になっている。
`build_epub.py` の `METADATA["author"]` と `author_kana` を、KDPアカウントの著者名に
書き換えてから再ビルドすること。奥付にも同じ名前が入る。

## 4. ★表紙

KDPは表紙ファイルが必須。ここでは作っていない。

- サイズ　1600 × 2560 px（推奨。縦横比 1 : 1.6）
- 形式　JPEG または TIFF、RGB、72dpi以上、50MB未満
- 文字　タイトル『最後の帳簿』／サブタイトル『三つに分けられた遺産』／著者名

**中身に合う案**（デザイナーに渡す場合の指示）

1. **四つのネジ穴。** 砂壁に、腰の高さで等間隔に並ぶ穴だけ。手すりはない
2. **和綴じの帳面の背。** 綴じ糸が二種類（切れて掛け替えた跡）
3. **急な木の階段を下から見上げる。** 片側は壁、片側は何もない

いずれも人物を出さない。色は紺と生成り。
