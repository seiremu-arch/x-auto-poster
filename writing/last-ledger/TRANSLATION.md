# 英語版の方針と対訳表

『最後の帳簿　三つに分けられた遺産』の英訳。`manuscript/` が原本、`manuscript-en/` が訳文。

## 基本方針

1. **舞台は日本のまま。** 翻案ではなく翻訳。円は円、法制度は日本の法制度、
   群馬は群馬。英語圏の読者に「翻訳された日本のミステリー」として読ませる。
2. **人名は英語式の語順**（名→姓）。Shuji Kamiya, Soichiro Tono。
   市販の日本ミステリー英訳の多数派に合わせた。
3. **法律用語に脚注をつけない。** 本文の中で一度だけ説明する。
   この小説は法律の説明を人物の台詞でやる作りなので、そこに乗せられる。
4. **文体を保つ。** 短い平叙文。感情の形容詞を使わない。数字に仕事をさせる。
   受動態を避ける。段落は短く。`※` の区切りはそのまま。

## 数字の対比をどう移すか（重要）

日本語版では、帳簿の古い行が**漢数字**、宗一郎の最新の一行だけが**算用数字**、
という字体の対比で「この一行だけが現代のもの」を示していた。
英語には漢数字がないので、**和暦と西暦の対比**に置き換える。

| | 日本語版 | 英語版 |
|---|---|---|
| 歴代の行 | 昭和十六年十二月 | *Showa 16, twelfth month* |
| 〃 | 昭和二十三年 | *Showa 23* |
| 〃 | 平成三年 | *Heisei 3* |
| 宗一郎の行 | 2026年2月10日 | **February 10, 2026** |

第一章の「この帳面で唯一、算用数字だった」は
"the only line in the book written in the Western calendar" になる。
エピローグの年号一覧も同じ規則。

## 帳簿の七つの記号

本文では漢字を出し、地の文で意味を添える。以降は英単語で受ける。

土 earth ／ 種 seed ／ 木 tree ／ 蜜 honey ／ 鍵 key ／ 手 hand ／ 水 water

## タイトル

- シリーズ: **The Last Ledger**
- 第1巻: **The Last Ledger: An Estate in Three Parts**
- キャッチ: *He left three hundred million yen. Each heir may take only one third of it.*
  （旧案の「three keys」は本文に対応するものがないので捨てた）

## 翻訳中に見つけて直した原文の傷（第18〜27章）

| 章 | 直したこと |
|---|---|
| 18 | 2月9日18時前の宇賀野は日没後。「まだ明るかった」→「もう暗かった」 |
| 21 | 手すりは「両端に金具」なのにブラケットが「4つ」。ネジ4本・穴4つに合わせてブラケット2つに（第23章とも一致） |
| 21 | 地の文の「三十年」を算用数字に（数字規則） |
| 22 | 亮介の2月8日のアリバイが、実際には確認されていない（第18章で確かめたのは11日）。「確かめるまでもなかった」に |
| 22 | 克巳の条件三。「受け渡し簿に記帳はない」は千鶴の行と矛盾するので「その日の欄に克巳の名前はない」に |
| 23 | 解体の見積もりは2月4日。「3月に見積もりも取っています」→「2月に」 |
| 23 | 10日に投函したのは遺言ではなく手紙と帳簿。「これを私宛に投函」→「私宛の手紙を投函」 |
| 24 | 手すりが外れた日（8日）と宗一郎が気づいた日（9日）の書き分けが最後の段で崩れていた |
| 9,20,23,25,26 | 克巳は宗一郎の**弟**なので、千鶴から見て「伯父」ではなく「叔父」（妻は「叔母」）。全箇所を修正 |
| 25 | 「妻の介護。伯母の介護」は視点が混ざっていた。千鶴の側にそろえて「母の介護。叔母の介護」／「使送先」→「送付先」 |

英語版側では、第9章で訳し落としていた「何かが揃っていない気がした…一つ手前の前提が
間違っていた」の段落を戻した（エピローグで同じ段落が反復されるため）。
