# KDPメタデータ

制作台帳 工程04。全作品共通。

## 登録テンプレート

1. **タイトル**
2. **サブタイトル**
3. **シリーズ名＋巻数**
4. **著者** ── Kazu A. Suzuki
5. **紹介文** ── 4,000字未満。構成は **フック → あらすじ → シリーズ情報＋「各巻単独で読めます」**
6. **キーワード7つ** ── 各50字未満

出版社は **Boundary Japan**。

## キーワードは説明句ではなく、実際に読者が打つ検索語

タイトル・サブタイトル・シリーズ名・著者名に**すでに入っている語は重複させない**。
7枠を説明で埋めず、検索窓に実際に入力される語に使う。

## シリーズ名は意図的にアバウトな広い名称にする

狭義のシリーズ名にすると多言語展開が複雑になるため。
