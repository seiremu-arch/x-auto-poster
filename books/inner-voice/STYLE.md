# 文体ルール — 『いちばん小さい声』

読者が自分で確かめられることだけを書く。確かめられないことを断定した瞬間に、
この本の立場(→ Vault `0adde001a2`)が崩れる。

## 人称と距離

- 書き手は「私」。読者は「あなた」
- 読者の状態を決めつけない。「あなたは疲れている」ではなく「疲れているとき」
- 教えない。**並んで見る。** 「〜しましょう」より「〜してみる」「私はこうしている」
- 体験を語るときは、うまくいかなかった側も書く。成功例だけを並べない

## 使わない語

検証できない語に寄りかからない。表紙・内容紹介でも使わない。

> 宇宙 / 波動 / 引き寄せ / エネルギー(比喩としても)/ 覚醒 / 次元 / 浄化 /
> 魂の使命 / 本当の自分 / ハイヤーセルフ / 潜在意識(定義なしで)/ エゴ(定義なしで)

「必ず」「誰でも」「絶対に」「〜が変わります」も使わない。効果の断定になる。

例外は1か所だけ。序章の「この本には宇宙も波動も出てこない」は、使わないと宣言する文なので残す。
それ以外で禁止語が本文に出てきたら、それは書き手が滑っている。

```bash
grep -nE "宇宙|波動|引き寄せ|エネルギー|覚醒|次元|浄化|魂の使命|本当の自分|ハイヤーセルフ|潜在意識|エゴ|必ず|誰でも|絶対に" \
  books/inner-voice/manuscript/*.md
```

端末は「スマホ」で統一する(「携帯」「電話」は使わない。通話そのものを指すときだけ「通話」)。

## 使う語

> 声 / 静けさ / 余白 / 体 / 速さ / ゆるむ / 締まる / 戻る / 数える / 聞き分ける

これらは本書の用語なので、章をまたいで意味を変えない。
新しい用語を足したくなったら、まずこのリストに入るかを見る。

## 文の作り

- 1文は60字まで。2つのことを言っている文は割る
- 1段落は3〜4文。段落の1文目に、その段落で言いたいことを置く
- 抽象名詞で始めない。**場面から入る。** 「不安とは」ではなく「夜、電気を消したあとに」
- 比喩は1章に2つまで。多いと、比喩のほうが記憶に残る
- 断定してよいのは**手順**だけ。「まず紙を用意する」は言い切る

## 見出しと記法

- 章タイトルは `#`、章内の節は `##`。`###` は実践の手順の中だけで使う
- 実践の手順は番号リスト。所要時間を最初の行に書く
- 強調は `**` のみ。1つの節に2か所まで
- 引用(`>`)は、読者が書き写す一文にだけ使う

## 安全に関わる書き方

- 心身の不調を本書のワークで解釈させない。第3章と巻末の両方に免責を置く
- 「受診しなくていい」と読める書き方をしない。迷ったら受診をすすめる側に倒す
- 眠れない・涙が止まらない・体が動かない、が続く場合は実践を止めてよいと明記する

## 引用

- 他者の文章を引用するときは、出典(書名・著者・訳者)を必ず本文か巻末に書く
- 短い引用にとどめる。宗教・思想の言葉を教義として扱わない
- 原稿はすべて書き下ろし。既存の文章を写さない(KDPの規約と、単純に作品として)
