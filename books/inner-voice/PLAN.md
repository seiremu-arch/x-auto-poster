## 誰に向けて書くか

決めることが多く、人の意見に触れる量も多い人。夜になっても頭の中が止まらず、
「自分がどうしたいのか分からない」という感覚がある。

スピリチュアルなものに関心はあるが、断定的な物言い(「宇宙が」「波動が」)には
引っかかりを覚える。**神秘を求めているのではなく、静けさを求めている。**

## この本が約束すること

読み終えたときに、読者はこの3つを持って帰る。

1. 頭の中で喋っている声を、4種類に分けて名前をつけられる
2. 「これは自分の声か」をその場で確かめる基準を2つ持つ — **速さ**と**体の反応**
3. 迷ったときに戻れる実践を7つ持つ(1つ5〜15分。道具は紙とペンだけ)

## 芯にする一文

> 内なる声は大きくならない。だから、こちらが静かになるしかない。

全章がこの一文の分解になっている。章が芯から離れたら、その章は削る(→ Vault `0adde001a2`)。

音量を基準から外した代わりに置く2つの基準も、Vaultに根拠がある。
**速さ**(→ `6e9d28f8ea`、第2章)/ **体の反応**(→ `100f1d5f68`、第3章)。

## やらないこと

- **効果を断定しない。** 「必ず」「誰でも」「〜が変わります」を書かない
- **医療・心理療法の代替として書かない。** 巻末に免責を置き、本文でも受診を否定しない
- **検証できない語に寄りかからない。** 使わない語は `STYLE.md` に列挙する
- **特定の宗教・団体の教義に依拠しない。** 引用するときは出典を明記し、教義としては扱わない
- **読者の状態を決めつけない。** 「あなたは疲れている」ではなく「疲れているとき」と書く

## KDPの制約から来る設計

- **電子書籍には書き込めない。** ワークはすべて「手元のノートに書く」前提で手順を書く。
  書き込み欄を紙面に作らない
- **リフロー型で出す。** 固定レイアウト・図表に依存しない。実践の手順は番号リストで表現する
- **サンプル(冒頭10%)で判断される。** 序章の終わりまでに「4つの声」の予告を出し、
  第1章の実践1を無料範囲に入れる
- **KENP(読了ページ)で収益が動く。** 各章末に次章への短い接続を置き、章の切れ目で止まらせない

## KDP登録メタデータ(案)

- カテゴリ: 「実用 > 自己啓発」/「暮らし・健康・子育て > メンタルヘルス」(2つまで選択)
- キーワード(7つまで): `内省` `自己対話` `ジャーナリング` `静けさ` `直感` `決断` `マインドフルネス`
- 表紙: 余白の多い1色ベース。中央に細い明朝でタイトル。人物・光線・宇宙的な意匠は使わない
  (本文で使わない語を、表紙で先に言ってしまわない)
- 内容紹介: 「頭の中がうるさい」から入り、4つの声 → 2つの基準 → 7つの実践 の順で3段落

## 進め方

章を1つ書くごとに、この順で回す。

```bash
python scripts/build_book.py inner-voice --check   # 字数を見る + 芯の一文の一致を検証
```

1. `OUTLINE.md` のその章の行を読み、主張が1文で言えるか確かめる
2. 章を書く(`manuscript/`)
3. 字数を見て、目安から±20%を超えていたら削るか足す
4. 芯の一文から離れていないか確かめる。離れていたらVaultに追記してから構成を変える
   (芯の一文を書き換えるときは、`book.json` ・このファイル ・claim `0adde001a2` ・
   `vault/MEMORY.md` を同時に直す。`--check` が落ちるので忘れられない)
