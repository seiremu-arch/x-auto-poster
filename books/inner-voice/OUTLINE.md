# アウトライン — 『いちばん小さい声』

各章は**1つの主張**と**1つの実践**を持つ。2つ言いたくなったら章を割る。
芯の一文(「内なる声は大きくならない。だから、こちらが静かになるしかない」)から
離れた章は削る。

## 章に共通する型

1. **情景**(300〜600字)— 具体的な一場面から入る。抽象名詞で始めない
2. **見立て**(1,200字)— その場面で何が起きているか
3. **基準**(800字)— この章で使う見分け方。読者がその場で確かめられる形にする
4. **実践**(1,000字)— 所要時間・手順(番号リスト)・書き出す問い3つ
5. **つまずきやすいところ**(600字)— よくある詰まり2〜3個に短く答える
6. **章の終わりに**(2〜3行)— 1行のまとめ + 次章への接続

## 章ごとの中身

### 序章 いちばん大きい声が、いつも正しいわけではない

- 情景: 決めなければいけないことがある夜。スマホを置いても頭が止まらない
- 見立て: 頭の中で喋っているのは1人ではない。それを1人だと思っているから、
  いちばん大きい声が「自分の考え」になってしまう
- この本の立場: 内なる声を**見つける**のではなく**聞き分ける**。探しに行かない
- 使い方: ノートを1冊用意する / 章の順に読む(基準 → 環境 → 決断の順に積む)/
  1章1週間でもいい / 実践は1つずつ
- 約束しないこと: 効果の断定をしない。医療の代わりにはならない
- 予告: 4つの声(不安・べき論・借りもの・内なる声)

### 第1章 いま、何人が喋っているか

- 情景: 友人に「その仕事、辞めたら?」と言われた翌日。その一言が頭の中で増殖する
- 見立て: 4つの声の輪郭
  - **不安の声** — 速い / 繰り返す / 未来形(「〜になったらどうする」)
  - **べき論の声** — 正しさの語彙(「普通は」「ちゃんと」「いい年して」)
  - **借りものの声** — 誰かの言い回しがそのまま入っている。声色がある
  - **内なる声** — 遅い / 短い / 一度しか言わない / 現在形
- 基準: 「どれが本物か」から始めない。**まず何人いるかを数える**。
  名前がつくと、声は勝手に分かれる
- 実践1 声の書き出し(10分)
- つまずき: 全部が不安に見える / 内なる声が1つもない / 書くほどうるさくなる
- 接続: 数えたら、次は速さで分ける

### 第2章 速さで見分ける

- 情景: 誘いのメッセージに「行きます」と即答した3日後、気が重くなっている
- 見立て: 反射は自分の意思に見える。速さは確信ではなく、**慣れ**の証拠
- 基準: 来た順に並べる。1番目は不安、2番目はべき論、内なる声は最後に来ることが多い
- 実践2 24時間ルール(即答しない技術。断り方の文例も置く)
- つまずき: 遅らせると相手に悪い / 遅らせても答えが来ない(それも答え)
- 注意: 「遅い=正しい」ではない。先延ばしとの違いは、体の反応で分ける(→ 第3章)

### 第3章 体で見分ける

- 情景: 内見した部屋。条件は完璧なのに玄関で肩が上がっている
- 見立て: 体は言葉より先に答えている。ただし体は「正しさ」ではなく「安全」を答える
- 基準: **ゆるむ / 締まる** の2つだけを見る。胸・喉・肩・呼吸の深さ
- 実践3 二択を体で試す(5分。片方を声に出して言い、10秒待つ)
- つまずき: 何も感じない(疲労時は出にくい)/ 怖さとワクワクの区別
- 注意: 体調不良のサインを本書のワークで解釈しない。受診を遅らせない

### 第4章 静けさをつくる

- 情景: 5分空いた瞬間に手が伸びる
- 見立て: 情報を断つ話ではない。**余白の置き方**の話。
  静けさは無音ではなく、次の入力が来ない状態
- 基準: 1日のどこに7分の隙間があるか(通勤・入浴後・寝る前)
- 実践4 7分の何もしない時間(何もしない、の定義を具体的に)
- つまずき: 退屈に耐えられない / 眠ってしまう / 続かない(週2回でいい)

### 第5章 書いて聞く

- 情景: 「どうしたらいいか」とノートに書いて、10分手が止まる
- 見立て: 問いが大きすぎると、答えられるのは不安の声だけになる
- 基準: 問いを三段に割る。**何が起きたか → 何が嫌だったか → 何ならできるか**
- 実践5 三段の問い(15分)
- つまずき: 書くことがない / ネガティブしか出ない / 読み返すのが怖い(読み返さなくていい)

### 第6章 小さく決める

- 情景: 「人生を変える決断」を3年間していない人が、金曜の夜に予定を1つ断る
- 見立て: 分岐点は、あとから見て分岐点だったと分かる。
  そのときは「どちらでもいい小さいこと」の顔をしている
- 基準: 決断の大きさではなく、**取り消せるかどうか**で分ける。
  取り消せる決断は、考えずに試したほうが速い
- 実践6 いちばん小さい一歩(72時間以内に終わるサイズまで割る)
- つまずき: 小さすぎて意味がない気がする / 一歩目で失敗した

### 第7章 聞こえない日の戻り方

- 情景: 実践を3週間続けたあと、まったく何も聞こえない日が来る
- 見立て: 声が消えたのではなく、こちらが速い。速さは自分では気づけない
- 基準: 聞こえないときに探さない。**探すのをやめて、戻る場所に戻る**
- 実践7 戻るための3行(いま見えるもの / いま聞こえる音 / いま体が触れているもの)
- つまずき: ずっと聞こえない時期がある(季節のように扱う)/ 本書を開けなくなった日

### 終章 静けさは目的地ではない

- 静かな人になる本ではない。うるさい日に戻れる場所を持つ本だった
- 4つの声は消えない。消さなくていい。数えられればいい
- 最後に1つだけ持ち帰るなら、実践7
