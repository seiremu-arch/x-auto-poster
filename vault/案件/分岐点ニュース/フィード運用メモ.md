# フィード運用メモ

[[分岐点ニュース]] のフィードを足す・直す・止めるときの手順。

## 現在のフィード

| 表示名 | 分類 |
| --- | --- |
| NHKニュース(主要) | fact |
| NHKニュース(社会) | fact |
| 47NEWS(共同通信) | fact |
| 東洋経済オンライン | opinion |
| ダイヤモンド・オンライン | opinion |

## 追加のしかた

`config/feeds.json` の `feeds` 配列に足すだけ。スクリプト側の変更は不要。

```json
{
  "name": "表示名",
  "url": "https://example.com/rss.xml",
  "category": "fact"
}
```

- `category` は `fact` か `opinion` のみ。それ以外を書くと、記事は取得されるがどのセクションにも入らず**黙って捨てられる**(`collect_articles()` が `by_category` のキーに無いものを無視するため)。
- `name` が `_` で始まるエントリは `load_feeds()` に除外される。コメント用の枠として使える。

## 追加したら確認する

```bash
pip install -r requirements.txt
python scripts/generate_site.py
```

標準出力に記事数、標準エラーに失敗したフィードが出る。`docs/index.html` の差分も見る。

## 取れなくなったとき

ニュースサイトはRSSの配信終了・URL変更を予告なくやる。取得に失敗したフィードは落ちずに、ページ下部の `<details>` 「取得できなかったフィード」に理由付きで表示される。

1. まずブラウザかcurlでURLを直接叩き、404 / 403 / HTML返却のどれかを確認する
2. 配信URLが変わっただけなら `config/feeds.json` の `url` を差し替える
3. 配信自体が終わっていればエントリごと削除する

放置するとページ下部にエラーが出続けるだけで、他のフィードには影響しない。→ [[RSSフィード収集]]

## 件数の上限

`scripts/generate_site.py` の定数で調整する。

- `MAX_ARTICLES_PER_FEED = 8` — 1フィードから拾う最大件数
- `MAX_ARTICLES_PER_CATEGORY = 20` — 事実/意見それぞれの掲載上限

フィードを増やすと1媒体あたりの露出が薄まるので、増やすときは `MAX_ARTICLES_PER_CATEGORY` も一緒に見直す。
