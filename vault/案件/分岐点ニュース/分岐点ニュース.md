# 分岐点ニュース

## 概要

RSSフィードから直近のニュースを集め、「事実」と「意見」に分けて毎朝自動更新する静的サイト。GitHub Actionsが毎日ニュースを取得して `docs/index.html` を再生成し、GitHub Pagesで公開する。リポジトリは `x-auto-poster`。

## 現状

- 収集対象は5フィード(事実3・意見2)。設定は `config/feeds.json`。
- 生成スクリプトは `scripts/generate_site.py` 単体。外部依存は `feedparser` のみ。
- ワークフロー `.github/workflows/daily-update.yml` が毎日 06:00 JST(21:00 UTC)に実行され、差分があれば自動コミット・プッシュする。
- 実際に毎日 `chore: update daily news (YYYY-MM-DD)` のコミットが積まれており、自動更新は動いている。
- GitHub Pagesの公開設定(Settings → Pages で `main` / `/docs`)は手動で1回だけ必要。
