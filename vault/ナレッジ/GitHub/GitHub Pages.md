# GitHub Pages

## 要点

`main` ブランチの `/docs` フォルダを配信する構成が、静的サイトでは一番手数が少ない。ただし**公開設定はpushでは有効化されない**ので、リポジトリ管理者がGUIで1回だけ設定する必要がある。

## 詳細

### 初回設定(手動・1回だけ)

1. リポジトリ → **Settings** → **Pages**
2. **Source** を `Deploy from a branch`
3. Branch を `main` / フォルダを `/docs` にして **Save**

公開URLは `https://<owner>.github.io/<repo>/`。

### /docs 方式を選ぶ理由

- `gh-pages` ブランチを分けるより、生成物と生成スクリプトが同じブランチに並ぶので追いやすい
- Actionsのデプロイジョブが不要。ファイルをコミットするだけで公開される
- 代わりに、リポジトリに生成物のコミットが毎日積まれる([[GitHub Actions]] の自動コミット)

### 注意点

- `docs/index.html` は生成物なので手で編集しない。次回の生成で上書きされる。
- Jekyll が走るため、`_` で始まるファイル/フォルダは無視される。素のHTMLを置くだけなら `docs/.nojekyll` を置いてビルドを飛ばすのが安全。
- 反映には数十秒〜数分かかる。プッシュ直後に見えなくても慌てない。
- 公開されたページは誰でも見られる。プライベートリポジトリでも Pages を公開にすると中身は外から読める。
