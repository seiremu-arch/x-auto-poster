# ノート作成スクリプト

`scripts/new_note.py` の使い方。[[運用ルール]] の「案件は1フォルダ+同名ハブノート」「作ったら [[ホーム]] から必ずリンクする」を毎回手でやらなくて済むようにしたもの。

## 使い方

```bash
# 案件を作る → vault/案件/新しい案件名/新しい案件名.md
python scripts/new_note.py 案件 "新しい案件名"

# ナレッジを作る → vault/ナレッジ/GitHub/トピック名.md
python scripts/new_note.py ナレッジ "トピック名" --分野 GitHub
```

依存ライブラリなし(標準ライブラリのみ)。リポジトリのどこから実行してもよい。

## やってくれること

- フロントマター(`type` / `created` / `updated` / `tags`)入りの雛形を作る
- 案件は `案件/<名前>/<名前>.md` の形にフォルダごと作る
- [[ホーム]] の該当セクションのリスト末尾にウィキリンクを追記する
- ナレッジで未知の分野を指定した場合、`## ナレッジ` の下に `### <分野>` の見出しごと作る

## やってくれないこと

- **関連ノートへのリンク張り**。ここは中身を分かっている人間(またはClaude)が書く。作成後に「使っている案件」「関連」へ最低1本張る。
- 既存ノートの更新。同名のノートがあるとエラーで止まる(上書きしない)。

## 注意

- タイトルに `/ \ : | # ^ [ ]` は使えない。ウィキリンクが壊れるため弾いている。
- `updated` は作成時の日付が入るだけ。以後の更新は手で直す。
