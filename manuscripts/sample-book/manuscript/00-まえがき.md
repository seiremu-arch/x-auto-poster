# まえがき

原稿を書き終えてから本ができるまでのあいだには、驚くほど多くの単純作業がある。章ごとにファイルを並べ替え、見出しのフォントを揃え、目次を作り直し、電子書籍版とペーパーバック版で別々のファイルを保存する。書き直すたびに、その全部をもう一度やる。

本書が扱うのは、その「もう一度」をなくすための工程だ。原稿はMarkdownで書く。判型や余白や目次の設定は`book.yaml`に書く。あとはコマンドを一度叩けば、KDPにそのまま入稿できるdocxとEPUBが出てくる。

手作業をやめると、原稿の直しが怖くなくなる。第3章まで書いてから第1章の構成を変えたくなっても、ファイルを編集してビルドし直すだけで、目次もページ番号も奥付もついてくる。推敲の回数は、そのまま本の質になる。

＊　＊　＊

本書のコードはすべて実際に動く。読みながら手を動かしたい場合は、リポジトリを手元に置いて、次のコマンドから始めてほしい。

```bash
python scripts/build_book.py manuscripts/sample-book
```

この原稿自体が、そのコマンドの入力になっている。
