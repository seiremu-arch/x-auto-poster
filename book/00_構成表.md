# 『夢編集局』シリーズ構成表

同じ世界を舞台にした連作短編集を、十二話ずつ一冊にまとめてKDPで出す。
案が足りなくなった巻は、新作を書いて枠を埋める。

## 全体の方針（確定事項）

- 星新一賞に応募するのは『境界線、未編集』**一本のみ**。応募規定が未発表原稿に
  限るため、この一本は**KDPには収録しない**。原稿は `novel/` に置き、
  `book/` には複製を残さない
- KDP版は、残りの二十二案を十二話ずつ二冊に分ける
- 第一巻は二十二案から十二話、第二巻は残り十話に新作二話を足して十二話にする
- 各巻は独立して読み終われるようにする。前巻の未収録作を読まないと落ちが
  分からない作りにはしない

### 第一巻の落ち

最終話『沈黙の被験者』で、夢編集技術がもともと意識不明患者と対話するために
生まれたことを明かす。主人公は患者の夢に入れる数少ない読み手で、ある患者の夢に
外部から漏れるはずのない情報が紛れ込み始める。最後に主人公自身が、自分が
目覚めているのか確信を持てなくなる。

均し計画は第一巻では背景に留め、決着させない。第二巻の主題として引き継ぐ。

### 第二巻の注意点

第十二話は、均し計画に決着をつける最終話になる。『境界線、未編集』とは
**別の結末**にしなければならない。同じ「編集対象は現実だった」という反転を
使うと、応募作と実質同一の作品をKDPで出したことになり、星新一賞の未発表要件に
触れるおそれがある。第二巻の最終話は、同じ世界の別の断面から書く。

第九話『明日の夢』は、当初この世界の規則（合意が現実を作る）と衝突するとして
除外していた。第二巻に入れるなら、未来予知ではなく「編集の予約記録が
先に確定してしまう」という形に設定を寄せて整合を取る。

## 全話にまたがる仕掛け

1. **半色** … 一晩に動かせる情動荷重の上限〇・〇五。全話に登場させる
2. **残差** … 押しても戻ってしまう素片。第一巻第一話の第七節で提示済み
   （少女が七晩ぶんの編集を一月で押し戻す）。第一巻では「無視してよい値」と
   説明されるままにしておき、第二巻で意味を与える
3. **削らずに、削ったと記録することはできるか** … 技師が追い詰められたときに
   必ず出す照会。第一話で、この照会を出した技師は数か月内に資格を返納すると
   示した。各話の技師にこの問いを言わせ、誰が返納し誰が残るかで人物を描き分ける
4. **校正官** … 各話に必ず一度は登場させる。話が進むほど言葉数が増える
5. **紙コップの水** … 技師にできる唯一のこと。第一話で確立し、以降くり返す
6. **要は換気です** … 制度の側の人間が必ず言う台詞。悪意はない声で言わせる
7. **緑色の歩道橋** … 消えたのに覚えている者がいるもの。第二巻の背景に置き、
   第二巻の最終話で意味を与える。第一巻では出さない
