# 付録 実践チートシート

---

## A. 頻出プロンプト集

### 新しい機能をお願いするとき

```
〔目的〕〔今の状況・前提〕を踏まえて、〔具体的にしてほしいこと〕を作ってください。
まずは〔範囲〕だけで構いません。
```

例:
```
8席のカフェの予約を管理したいです。今は電話とLINEで予約を受けていて、
二重予約がよく起きています。まずは、日時・人数・お客様名を入力して
一覧で確認できる画面だけを作ってください。
```

### 修正・調整をお願いするとき

```
〔今の状態〕はいいのですが、〔変えてほしい部分〕を〔どう変えたいか〕にしてほしいです。
```

例:
```
一覧はいい感じですが、日付の並び順を新しい順にしてほしいです。
```

### トラブルを伝えるとき

```
〔いつ〕気づきました。〔何が〕起きています。
直前に〔何をしたか〕をしていました。
画面には次のように表示されています:
〔エラーメッセージをそのまま貼り付ける〕
```

### 動作確認・レビューを依頼するとき

```
今の変更を実際に動かして確認してください。特に〔わざと崩す操作の例〕も
試してみてください。
```

```
この変更についてレビューしてください。特に、動作に関わる問題がないか
重点的に見てください。
```

### Git・GitHub関連の依頼

```
ここまでの変更を、わかりやすいメッセージをつけて記録(コミット)しておいてください。
```

```
〔試したいこと〕を試すための新しいブランチを作ってください。
```

```
ここまでの変更をGitHubに送っておいてください。
```

```
〇〇さんの変更と自分の変更が、同じ部分でぶつかっているようです。
それぞれの内容を整理して、どうするのが良いか提案してください。
```

## B. 用語集

| 用語 | 意味 |
|---|---|
| Cursor | AIが組み込まれたコードエディタ。VS Codeをベースにしている(第1章) |
| プロンプト | AIへの指示・依頼の文章(第2章) |
| Claude Code | ターミナルの中で会話しながら、ファイルの作成・編集・動作確認まで行うAIエージェント(第3章) |
| ターミナル(CLI) | 文字を打ち込んでコンピュータを操作する画面(第3章) |
| エラーメッセージ | 何かがうまくいかなかったときに表示される、原因の手がかりとなる文言(第5章) |
| Git | ファイルの変更履歴を記録し、過去の状態に戻れるようにする仕組み(第6章) |
| コミット | Gitで、ある時点の状態を記録として残す操作(第6章) |
| GitHub | Gitの記録をインターネット上に保管・共有できるサービス(第7章) |
| リポジトリ | ひとつのプロジェクトに対応する、GitHub上の保管場所(第7章) |
| push / pull | パソコンとGitHubの間で記録を送る/取り込む操作(第7章) |
| ブランチ | 本流に影響を与えずに試行錯誤できる、枝分かれした作業場所(第8章) |
| プルリクエスト(PR) | ブランチでの変更を本流に合流させるための手続き(第8章) |
| マージ | ブランチの変更を本流に合流させること(第8章) |
| コードレビュー | 変更内容を実装者以外の視点(AI・人間)で確認する作業(第9章) |
| Issue | あとで対応したいことを記録しておく、課題管理の仕組み(第9章) |
| デプロイ | アプリを誰かが使える状態にして公開すること(第10章) |
| コンフリクト | 複数の変更が同じ箇所にぶつかり、自動では合流できなくなる状態(第11章) |

## C. トラブルシューティング表

| 症状 | まず試すこと |
|---|---|
| AIに頼んだ結果が的外れ | 目的・状況・具体的な要望の三つが指示に含まれているか見直す(第2章) |
| 何を頼んでも思った通りにならない | 一度の依頼を小さく分け、一つずつ確認しながら進める(第4章) |
| 動いていたはずのものが動かない | エラーメッセージの全文をそのままAIに見せ、「いつ・何が・直前に何をしたか」を伝える(第5章) |
| 「昨日は動いていたのに」が起きる | Gitでこまめにコミットする習慣をつける。過去の記録に戻れるようにしておく(第6章) |
| 新機能を試すのが不安 | 本流に直接手を加えず、ブランチを作って試す(第8章) |
| プルリクエストが合流できない | コンフリクトが起きている可能性が高い。状況をAIに伝えて整理してもらう(第11章) |
| 大きな変更で不安がある | 合流前にAI・人間の両方にレビューを依頼する(第9章) |
