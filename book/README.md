# 連作短編集『夢編集局』KDP出版プロジェクト

Amazon Kindle ダイレクト・パブリッシング（KDP）で出版する連作短編集の
制作用フォルダです。

**いまの状態：9言語 × 2巻 = 18冊。全24話の本文と、18冊ぶんの登録情報が
揃っています。** 残っているのはお手元での Kindle Previewer 確認とKDPへの
登録だけです。

---

## 1. 何を作っているのか

「AIが人の夢を編集できる世界」を舞台にした連作短編集です。十二話ずつで
一冊、二冊で全二十四話。

十二話は独立して読めますが、全部同じ世界の話です。読み進めるほど、
この世界が何なのかが分かっていく作りになっています。

**第一巻『夢編集局』** … 技師と申請者が向かい合って座る話。
半色（一晩に動かせる上限 0.05）という制約と、書式に欄がないものが
どこへ行くのかが通しの主題です。

**第二巻『均し』** … 同じ技術が、産業になり、制度になり、国の大きさに
なったあとの話。第一巻は要りません。第八話だけは第一巻の三話から文を
そのまま引用しますが、引用の意味は第二巻の中で閉じています。

話の順と字数は [`00_構成表.md`](00_構成表.md)、全話で共通する用語と設定は
[`01_世界観設定.md`](01_世界観設定.md) にあります。

## 2. フォルダの中身

```
book/
├── README.md               このファイル
├── 00_構成表.md             両巻の収録一覧・字数・進行状況
├── 01_世界観設定.md          全話で共通する用語と設定（矛盾防止用）
├── KDP-メタデータ一覧.md     18冊の登録情報を1枚にまとめたもの（自動生成）
│
├── vol1/ vol2/             日本語（原文）
├── en/ en1/ en2/           English
├── de/ de1/ de2/           Deutsch
├── es/ es1/ es2/           Español
├── fr/ fr1/ fr2/           Français
├── it/ it1/ it2/           Italiano
├── nl/ nl1/ nl2/           Nederlands
├── pt/ pt1/ pt2/           Português（ブラジル）
├── id/ id1/ id2/           Bahasa Indonesia
│
├── dist/                   EPUBと表紙（18冊ぶん。gitに入れてある）
└── tools/                  下記
```

言語ごとに三つのフォルダがあります。

| フォルダ | 中身 |
|---|---|
| `xx/GLOSSARY.md` | その言語の用語集。**訳語はここが正本** |
| `xx1/` | 第一巻（`stories/` 12話・`PROGRESS.md`・`KDP登録情報.md`） |
| `xx2/` | 第二巻（同じ） |

三冊目以降を作るときは `vol3/` を足し、`build_epub.py` と
`build_cover.py` の `VOLUMES` に一行加えてください。

## 3. 道具

```bash
# 組む
python3 book/tools/build_epub.py vol1     # 巻を指定。省略すると18冊ぶん
python3 book/tools/build_cover.py vol1    # 表紙。PIL が要る

# 検査（4つとも0件で通ること）
python3 book/tools/check_tr_structure.py  # 段落数・字下げ・引用ブロック
python3 book/tools/check_tr_terms.py      # 用語ゆれ・組み方の規則
python3 book/tools/check_tr_quotes.py     # 巻をまたぐ引用と定型句
python3 book/tools/check_overlap.py       # 応募作との重なり

# 台帳
python3 book/tools/sync_tr_counts.py id1  # PROGRESS.md の語数表を同期
python3 book/tools/kdp_metadata.py        # 18冊の一覧を再生成＋食い違い検査
```

### 検査について（ここが肝です）

本文を一語でも直したら、**4つの検査を通してから終わります。** 通していない
ものを「訳了」と書くことはできません。実際にこのセッションで、第九話の
定型句が登録形から外れていたのを `check_tr_quotes.py` が拾いました。

`check_tr_structure.py` は、訳文が原文と**段落単位で対応している**ことを
前提にしています。この対応を保っているので、一段落抜け落ちると機械で
拾えます。訳文の読みやすさのために段落を割ったり繋いだりすると、この
検査が死にます。**読みやすさより対応を優先してあります。**

`kdp_metadata.py` は各巻の `KDP登録情報.md` を正本として読み、18冊の
一覧を書き出します。一覧を手で書くと、価格を一冊だけ直したときに古い
数字が残ります。実際にそれが起きたので道具にしました。初回の実行で
`de2` のISBN行の欠落と、`en1`・`es2` の語数の古さを拾っています。

### 検査を足すときの規則

**足した検査は、わざと誤った入力を食わせて鳴ることを確かめてから
使ってください。** 鳴らない検査は、ないのと同じどころか、「通った」という
報告のほうが害になります。

このセッションでは、この手順で5件の検査側の誤りを見つけました。

| 症状 | 原因 |
|---|---|
| 伊語のダッシュ禁止が誤検知 | 正しい用法まで弾いていた |
| `check_total` の正規表現が合わない | 行をまたぐ書き方を想定していなかった |
| 葡語の `tecnicamente` を誤検知 | `\btecnic\w*` が広すぎた。副詞は強勢が移るので記号が付かない |
| 尼語のマレー語検査が鳴らない | `\bfikir\w*` は接頭辞で語境界が消え `berfikir` に当たらない |
| 尼語の di- 検査が鳴らない | 検査本体に `IGNORECASE` がなく、文頭の `Diluar` に当たらない |

この5件は二種類に分かれます。**鳴りすぎたもの**（伊語のダッシュ、
葡語の `tecnicamente`）と、**鳴らなかったもの**（残りの3件）です。

前者から出てくる規則：**新しい検査が完成済みの仕事に対して失敗を
報告したときは、まず検査を疑ってください。**

後者から出てくる規則：**通ったという報告は、その検査が鳴ることを
確かめていなければ意味がありません。**

## 4. 翻訳の方針

### 全部、日本語の原文から訳しています

重訳はしていません。英語版を経由すると、英語版の解釈が8言語に伝播します。

### 語数比（原文1字あたり）

**ここに表を置きません。** 手で書くと、訳文を一語直したときにここだけ
古くなります（実際に一度やりました）。実測値は
[`KDP-メタデータ一覧.md`](KDP-メタデータ一覧.md) の第2節にあり、
`kdp_metadata.py` が各巻から読み直して書き出します。

目安としては、仏語と蘭語がいちばん嵩み、尼語がいちばん嵩みません。
尼語が少ないのは、屈折も冠詞もないためです。語数は減りますが、
重ねや接辞で語が長くなるので、文字数は減りません。

各巻の `KDP登録情報.md` 第7節にも同じ数字を書いてあり、
`kdp_metadata.py` が実測と照合します。片方が古くなれば検査で止まります。

### 組み方は言語ごとに違います

| 言語 | 会話 | 約物前の空白 | 小数点 | 千の位 | 二人称 |
|---|---|---|---|---|---|
| 日本語 | 「　」 | — | 読点 | — | — |
| English | " " | なし | 点 | 読点 | you |
| Deutsch | „ “ | なし | 読点 | 点 | Sie |
| Español | — raya | なし | 読点 | 点 | usted |
| Français | — tiret | **入れる（nbsp）** | 読点 | nbsp | vous |
| Italiano | « » | なし | 読点 | 点 | Lei |
| Nederlands | “ ” | なし | 読点 | 点 | u |
| Português | — travessão | なし | 読点 | 点 | o senhor |
| Bahasa Indonesia | “ ” | なし | 読点 | 点 | Anda |

**仏語だけ約物の前に空白が入ります**（`ainsi :`）。他の7言語は逆の規則で、
入れると誤りです。検査で両方向を見ています。

全言語で共通するのは、書類からの引用を `　— `（表意文字空白＋全角ダッシュ）
で始めること、感嘆符を使わないこと、姓を先に書いて長音記号を使わないこと、
本文の行頭を U+3000 で始めることです。

### 近い言語どうしの混入検査

独語↔蘭語、西語↔葡語、馬来語↔尼語は、一語残っても読んでいて
気づきにくい。両語で形が違う綴りだけを並べた検査を置いてあります。

## 5. 星新一賞との関係（決定済み・変更不可）

日経「星新一賞」の応募規定は**未発表原稿に限る**と定めています。
KDPで出版した作品は「発表済み」になるため、応募できません。

| フォルダ | 用途 | 発表状態 |
|---|---|---|
| `novel/` | 星新一賞に応募する『境界線、未編集』一本のみ | **未発表を維持。KDPには入れない** |
| `book/` | 24話（9言語） | 出版する |

星新一賞は一人一作品までなので、応募できるのは『境界線、未編集』の一本
だけです。

`book/` の中に『境界線、未編集』の複製は置きません。応募作に固有の
要素（緑色の歩道橋、三崎・深瀬の名、「境界線、未編集」の題）が本文・
内容紹介のどこにも入っていないことを、`check_overlap.py` が
**全9言語について**機械で確かめます。

この検査は4つの観点を見ます。

1. 応募作の複製が `book/` 配下にないか
2. 16字以上で完全一致する文がないか（許容一覧の外）
3. 応募作固有の固有名詞（日本語）
4. 同じものの各言語訳（`Misaki` / `footbridge` / `jembatan penyeberangan` など）

4の各言語版は、**その言語を訳す前に**登録してあります。訳したあとに
登録すると、自分の訳文を見ながら禁止語を決めることになり、検査の意味が
なくなります。

なお、`bridge` / `Brücke` / `puente` / `ponte` / `brug` / `jembatan`
単独は**禁止していません**。第二巻第五話に橋を架ける話が出てくるためです。
歩道橋を指す複合語だけを弾いています。

## 6. KDPで出版する手順

### 用意するもの

1. **原稿（EPUB）** … `build_epub.py` で生成。`dist/` に入っています
2. **表紙（JPEG）** … `build_cover.py` で生成。1600×2560px（1.6:1）
3. **Amazonアカウント** … 普段の買い物用と同じで構いません
4. **銀行口座とマイナンバー** … 印税の受け取りと納税のために登録します

ISBNは**不要**です。KDPが内部管理用の番号を自動で振ります。

### 登録の順番

**各言語とも第一巻を先に登録してください。** シリーズ名を確定させてから
第二巻を出します。逆にすると、シリーズページが二つできることがあります。

貼り付ける中身は [`KDP-メタデータ一覧.md`](KDP-メタデータ一覧.md) に
18冊ぶん並べてあります。説明文・キーワード7つ・カテゴリー・価格が
一覧になっているので、登録画面を18回うめるときに18ファイルを開き直す
必要はありません。各巻の詳細は `xx1/KDP登録情報.md` にあります。

### 手順

1. <https://kdp.amazon.co.jp/> でアカウントを作る（1回だけ）
2. 「＋電子書籍または有料マンガ」を選ぶ
3. **本の詳細**を入力 — 一覧から貼り付け
4. **本のコンテンツ** — EPUBと表紙をアップロードし、Kindle Previewer で確認
5. **価格設定** — 一覧の推奨価格。70%プランの範囲内か登録画面で確認
6. 「Kindle本を出版」。審査は通常72時間以内

### ロイヤリティ

| 選択肢 | もらえる割合 | 条件 |
|---|---|---|
| 35%プラン | 定価の35% | 価格帯が広い。配信コストは引かれない |
| 70%プラン | 定価の70%から配信コストを引いた額 | 価格帯が狭く、市場ごとに違う |

18冊すべて70%プランを推奨しています。**使える価格帯は市場ごとに違う**ので
（米 $2.99〜9.99、独 2.99〜9.99 €、伯 R$ 5.99〜24.99 ほか）、登録画面に
出る範囲で確認してください。

### 付加価値税

手取りに効きます。一覧の「税」の列に市場ごとの税率を入れてあります。
電子書籍の軽減税率は国ごとに違い、**ブラジルは憲法上の免税**（電子書籍も
対象）、**日本は軽減税率の対象外で10%**です。

### KDPセレクト

90日間の独占と引き換えに、Kindle Unlimited に入ります。
**独占は言語版ごとに数えます。** ある言語版をセレクトに入れても、他の
言語版の扱いには影響しません。

## 7. インドネシア語版だけの注意

**インドネシア語がKDPの出版言語一覧にあるかどうか、登録画面の
ドロップダウンで確かめてください。**

調べた範囲ではKDPのヘルプ「Book Supported Languages」の一覧に
インドネシア語が見当たりませんでした。公式ページ自体はネットワーク制限で
開けておらず、確認できたのは第三者の記事までなので**断定はしていません**。
一覧は随時増えるので、登録画面が正本です。

選べなかった場合の手は三つ（他ストアに出す／English で登録する／保留する）。
詳しくは [`id1/KDP登録情報.md`](id1/KDP登録情報.md) 第1節にあります。
**判断は二巻で揃えてください。**

インドネシアにはAmazonのストアがないため、販売は amazon.com からの
国際販売になります。カテゴリーも英語ツリーから選びます。
