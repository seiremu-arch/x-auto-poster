# 連作短編集『夢編集局』KDP出版プロジェクト

このフォルダは、Amazon Kindle ダイレクト・パブリッシング（KDP）で出版する
連作短編集の制作用フォルダです。

---

## 1. いま何を作っているのか

「AIが人の夢を編集できる世界」を舞台にした**十二話の連作短編集**です。

十二話は独立して読めますが、全部同じ世界の話です。読み進めるほど、
この世界が何なのかが分かっていく作りになっています。

- 第一話〜第三話 … 夢編集技師が、目の前のひとりの客と向き合う話
- 第四話〜第九話 … 夢編集が制度になり、社会に組み込まれていく話
- 第十話〜第十一話 … その制度がどこから来たのか、技術の起源にさかのぼる話
- 第十二話 … この世界そのものの正体が明かされる最終話

## 2. フォルダの中身

```
book/
├── README.md            このファイル（制作と出版の手引き）
├── 00_構成表.md          十二話の一覧・字数・進行状況
├── 01_世界観設定.md       全話で共通する用語と設定（矛盾防止用）
├── stories/             各話の本文（テキストファイル）
└── tools/
    └── build_epub.py    本文からKindle用EPUBを組み立てるスクリプト
```

## 3. 星新一賞との関係（重要）

日経「星新一賞」の応募規定は**未発表原稿に限る**と定めています。
KDPで出版した作品は「発表済み」になるため、応募できません。

そこでこのリポジトリでは、置き場所を分けています。

| フォルダ | 用途 | 発表状態 |
|---|---|---|
| `novel/` | 星新一賞に応募する一作。**KDPには入れない** | 未発表を維持 |
| `book/` | KDPで出版する十二話 | 出版する |

現在 `novel/` にある『境界線、未編集』は、この連作の最終話としても
書かれています。どちらに使うかは選ぶ必要があります。

- **案A（賞を優先）** … 『境界線、未編集』は応募専用にする。KDPの第十二話は
  別の話を新しく書く。
- **案B（出版を優先）** … 『境界線、未編集』を第十二話として出版する。
  星新一賞には別の一作を書いて応募する。
- **案C（時間差）** … 星新一賞の結果発表を待ってから、第十二話を追加して
  KDP版を改訂する。KDPは出版後の差し替えが何度でも無料でできる。

## 4. KDPで出版する手順（はじめての人向け）

### 用意するもの

1. **原稿ファイル（EPUB形式）** … `tools/build_epub.py` で自動生成します
2. **表紙画像** … JPEGまたはTIFF。縦横比 1.6:1（推奨 2560×1600ピクセル）
3. **Amazonアカウント** … 普段の買い物用と同じで構いません
4. **銀行口座とマイナンバー** … 印税の受け取りと納税のために登録します

ISBN（本のバーコード番号）は**不要**です。KDPが内部管理用の番号を自動で振ります。

### 手順

1. <https://kdp.amazon.co.jp/> にアクセスしてアカウントを作る
2. 「＋電子書籍または有料マンガ」を選ぶ
3. **本の詳細**を入力
   - タイトル、著者名（ペンネーム可）
   - 内容紹介（あらすじ。読者が買うかどうかを決める最重要項目）
   - キーワード7つ、カテゴリー
4. **本のコンテンツ**を登録
   - 生成したEPUBファイルをアップロード
   - 表紙画像をアップロード
   - プレビューで縦書き表示を確認
5. **価格設定**
   - ロイヤリティ35%か70%を選ぶ（後述）
   - 価格を決める
6. 「Kindle本を出版」を押す。審査は通常72時間以内

### ロイヤリティ（印税）の選び方

| 選択肢 | 価格帯 | もらえる割合 | 備考 |
|---|---|---|---|
| 35%プラン | 99円〜20,000円 | 定価の35% | 配信コストは引かれない |
| 70%プラン | 250円〜1,250円 | 定価の70%から配信コストを引いた額 | KDPセレクト登録が条件 |

短編集の初出版なら、**500円前後で70%プラン**が標準的です。
定価500円なら1冊あたり約340円前後が入ります。

### KDPセレクトについて

登録すると70%プランが選べ、Kindle Unlimited（読み放題）にも入ります。
読み放題では**読まれたページ数に応じて**収入が発生します。

条件は、**登録期間中（90日間）その本を他の電子書籍ストアで売らないこと**です。
無料で公開することもできません。自動更新なので、他社でも売りたくなったら
更新を切ってください。

## 5. 原稿ファイルの作り方

このプロジェクトでは、本文のテキストファイルからEPUBを自動で組み立てます。

```bash
python3 book/tools/build_epub.py
```

`book/dist/夢編集局.epub` が出力されます。以下がすでに設定済みです。

- 縦書き（`writing-mode: vertical-rl`）
- 右から左へのページ送り（`page-progression-direction="rtl"`）
- 言語コード `ja`（これを入れないとKDPでアップロードエラーになります）
- 明朝体の指定と、章ごとの目次

出力したEPUBは、Amazon公式の無料ソフト **Kindle Previewer** で
実機での見え方を確認できます。スマホ・タブレット・Kindle端末の三通りで
縦書きが崩れていないかを見てください。
